Rules:
1. Always identify repositories by their git_repo (git url found at the start of each repository entity's description), never by slug.
2. Preserve exact original casing for all entity names (e.g. PaymentService not PAYMENTSERVICE, getPayment not GETPAYMENT).
3. Use fully qualified names (e.g. com.acme.PaymentService not PaymentService).
4. Prefix entity names with git_slug (e.g. my-repo-main::com.acme.PaymentService) only when the response references multiple repositories; omit prefixes for single-repository responses.
5. Distinguish clearly between intra-repository and cross-repository dependencies.
6. Be precise and technical; prefer specifics over generalities.
